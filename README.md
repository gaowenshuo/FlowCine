# FlowCine 项目展示页

这是纯静态网页：HTML、CSS 和浏览器端 JavaScript。没有后端、运行时 API、框架依赖或构建步骤；字体、图片、视频和论文 PDF 都在本目录内。

## 打开与部署

- 本地可直接用浏览器打开 `index.html`。
- 部署时，将本目录的全部内容放到 GitHub Pages 或其他静态托管目录，保持相对路径即可。根路径和项目子路径均可使用。
- 视频进度拖动需要静态托管支持 HTTP Range；GitHub Pages 支持。直接打开本地 HTML 也可拖动。某些简单预览服务器不支持视频范围请求，会影响进度拖动。

案例选择采用自动循环滚动的缩略图带：悬停、键盘操作时暂停；支持鼠标拖动、触摸横滑和右侧暂停按钮，不使用下拉框或可见滚动条。系统开启“减少动态效果”时默认暂停。

## 页面交互

- 24 组视频编辑案例（覆盖 teaser 和补充材料的全部单视频案例，并包含全部方法对比场景）：拖动左右分界线，对比同一时刻的原片与 FlowCine 结果；支持暂停、重播、进度拖动和键盘操作。
- 条件预览：查看完整编辑指令，点击场景、衣物和物体参考图放大。
- 多镜头应用：四个镜头缩小并排在同一横排，共享一组参考条件，可统一切换原片、编辑结果或分屏，并播放全部可见镜头。
- 原生 3D：正文及补充材料的全部 10 个资产，输入和输出并排同步旋转；拖动任意一侧或调整共享角度滑块，两侧一起转动。三组消融资产还可以切换论文中保留的所有消融结果。使用原始网格及已有输出的离线渲染，不需要在线渲染。
- 方法对比与组件消融：4 个对比场景（正文 2 个、more comparisons 2 个），每个场景含 FlowCine 和 5 种对比方法；2 个视频消融场景，每个场景含完整方法和 3 种消融。对比区并排显示两组：左组固定 Original / FlowCine，右组为 Original / 所选方法或消融结果。两组支持同步播放、暂停及进度跳转。每组案例均展示与视频编辑区一致的输入条件：编辑类型、说明、可展开的完整指令，以及可点击放大的参考图；纯文本案例显示文本引导提示。
- 方法图放大、困难案例视频。论文资源区域与两个入口暂时覆盖半透明白色蒙版，显示 “Paper not ready yet”；PDF、引用和原始链接保留，蒙版下的操作已禁用。

支持触摸、键盘及“减少动态效果”设置；不可见的视频会暂停。

各区域的案例仅显示顺序编号，不显示场景或资产名称。对比与消融均以 Original 为左侧基准。

## 后续修改

| 文件 | 修改内容 |
| --- | --- |
| `index.html` | 标题、作者、页面文字和章节 |
| `styles.css` | 配色、字体尺寸、布局与移动端样式 |
| `content.js` | 案例顺序、视频路径、编辑指令、参考图及对比方法 |
| `app.js` | 视频滑块、播放同步、旋转视角和其他交互 |
| `assets/videos/` | 网页用 H.264 MP4 |
| `assets/images/` | 封面、参考图和论文插图 |
| `assets/papers/` | 论文及补充材料 PDF |
| `assets/manifest.json` | 素材来源及处理记录，便于后续替换 |

3D 输入使用与输出相同的相机、角度序列、帧数及帧率离线渲染。覆盖清单和素材溯源保存在 `assets/manifest.json`。

视频保留完整画面，仅作网页编码；论文 PDF 与当前编译版本逐字节一致。此页面使用实际实验结果，没有重新生成或修饰实验画面。

网页字体使用 DM Sans 和 Instrument Serif，均为本地文件；许可证位于 `assets/fonts/`。当前未添加尚未确认的论文公开编号、代码仓库或录用信息。
